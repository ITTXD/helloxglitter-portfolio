# Plan: Wallpaper Admin Feature (Custom Download Links)

**Branch:** `feature/wallpaper-admin`

## 🎯 เป้าหมาย (Goal)
แอดมิน (แม่ค้า) สามารถ **"เพิ่มสินค้า Wallpaper ใหม่"** ได้เองจากหน้าร้าน (หน้า Wallpaper) โดยสามารถกำหนดชื่อ, ราคา, รูปภาพ และ **ลิงก์ดาวน์โหลด (Google Drive)** แยกเฉพาะของแต่ละลายได้เอง เมื่อลูกค้าสั่งซื้อและชำระเงินเรียบร้อย ลูกค้าจะได้รับลิงก์ดาวน์โหลดที่ตรงกับลายที่ซื้อไปเท่านั้น (Customized Download Link)

## 📋 แผนการพัฒนาและสิ่งที่ต้องตรวจสอบ (Implementation Plan)

### 1. ส่วนหน้าบ้าน (Frontend - Admin UI)
- [x] **ปุ่มเพิ่มสินค้า:** มีปุ่ม `＋ เพิ่ม Wallpaper ใหม่` ในหน้า `#page-wallpaper` (แสดงเฉพาะเมื่อ Log in เป็น Admin)
- [x] **Modal เพิ่ม/แก้ไขสินค้า:** ใช้ `hlgProductModal` โดยต้องเพิ่มช่องกรอก **"ลิงก์ดาวน์โหลด (URL)"** (แสดงเฉพาะตอนหมวดหมู่เป็น `wallpaper`)
- [x] **การบันทึก:** แก้ไข `hlgSaveProduct()` ให้ส่งค่า `download_url` แนบไปกับ Payload ส่งไปยัง `/api/products`
- [x] **การแสดงผลหลังเพิ่ม:** หลังจากบันทึกเสร็จ ต้องเรียก `renderWallpaperGallery()` ใหม่เพื่อให้การ์ด Wallpaper ลายใหม่แสดงขึ้นมาทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ

### 2. ส่วนตะกร้าและการสั่งซื้อ (Cart & Checkout Flow)
- [x] **ตะกร้า (Cart Sync):** เมื่อแอดมินหรือลูกค้ากดเลือก Wallpaper ระบบจะบันทึกลงตะกร้า (`hlg_unified_cart_v1`) และต้องดึง `download_url` ของสินค้านั้นๆ เก็บไว้ในตะกร้าด้วย
- [x] **สร้างออเดอร์ (Confirm Order):** ในตอนส่งข้อมูล Checkout ไปที่ `/api/orders/confirm` ข้อมูล Items ต้องมีฟิลด์ `download_url` ติดไปด้วย

### 3. ส่วนหลังบ้านและ API (Backend & Database)
- [x] **เพิ่มสินค้า:** `POST /api/products` และ `PUT /api/products/:id` ต้องรับและบันทึกฟิลด์ `download_url` ลงในฐานข้อมูล `custom_products`
- [x] **บันทึกออเดอร์:** `/api/orders/confirm` (หรือ `/api/wallpaper/order`) ต้องวนลูปดึงลิงก์จากรายการสินค้า (Items) แล้วรวมเป็น `download_links` (array ของ `{name, url}`) บันทึกลงใน Document ของ Order นั้นๆ ร่วมกับอีเมลลูกค้า
- [x] **ระบบเช็กลิงก์ของลูกค้า:** `GET /api/wallpaper/check?email=...` ต้องหา Order ของอีเมลนั้น กรองเฉพาะออเดอร์ที่ยืนยันแล้ว (`status === 1`) ดึง `download_links` ของทุกลายที่ลูกค้าซื้อส่งกลับไปให้หน้าเว็บแสดงผล

### 4. ส่วน Dashboard หลังบ้าน (Admin Dashboard)
- [x] **Modal ออเดอร์:** ในหน้า Dashboard (`public/admin/index.html`) เมื่อแอดมินกดดูรายละเอียดออเดอร์ที่มี Wallpaper ควรจะเห็นรายการ `download_links` ทั้งหมดของออเดอร์นั้น (หรืออย่างน้อยสามารถแก้ไขลิงก์ในกรณีที่ลูกค้ามีปัญหาได้)

### 5. การทดสอบ (Testing)
- [ ] แอดมิน Log in หน้าร้าน -> กดเพิ่ม Wallpaper -> ตั้งชื่อ "Cute Cat", ราคา 59, ใส่ลิงก์ `https://drive.google.com/cat` -> กดบันทึก -> การ์ดขึ้นทันที
- [ ] ลูกค้ากดเลือก "Cute Cat" -> สั่งซื้อ -> กรอกอีเมล `test@test.com` -> ยืนยัน
- [ ] แอดมินเข้าไปหลังบ้านเปลี่ยนสถานะเป็น "ยืนยันแล้ว"
- [ ] ลูกค้าเข้าหน้า "เช็คลิงก์ดาวน์โหลด" -> กรอก `test@test.com` -> ระบบแสดงปุ่มดาวน์โหลดลิงก์ `https://drive.google.com/cat` ของลาย "Cute Cat" อย่างถูกต้อง
